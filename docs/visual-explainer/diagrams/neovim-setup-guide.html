Neovim Setup Guide

chrysaki theme // lazyvim framework // vs code workflow

Your Neovim is built on LazyVim -- a pre-configured Neovim distribution that gives you IDE-level features out of the box. This guide shows how every piece fits together and maps VS Code shortcuts to their Neovim equivalents.

01

What is LazyVim?

The Framework

LazyVim is a Neovim distribution -- think of it as a pre-built IDE configuration. It uses lazy.nvim (a plugin manager) to install and manage ~30+ plugins that together give you autocomplete, syntax highlighting, file navigation, git integration, and more. You don't configure each plugin from scratch -- LazyVim provides sensible defaults.

How You Customize It

Your config lives in ~/.config/nvim/lua/. Files in plugins/ override or extend LazyVim's defaults. Files in config/ set your personal options and keymaps. LazyVim "extras" are optional feature packs (language support, UI enhancements) you enable in lazyvim.json.

VS Code Analogy

If VS Code is the editor + marketplace, LazyVim is like having a curated "VS Code Essentials" extension pack pre-installed. Each Neovim plugin is like a VS Code extension. lazy.nvim is the extension marketplace. lazyvim.json is your settings.json.

The Leader Key

In VS Code you use Ctrl+Shift+P to access everything. In Neovim, the Space key is your "leader" -- it opens a menu (which-key) showing all available actions. Press Space and wait -- you'll see every shortcut organized by category.

02

Vim Modes (The Core Concept)

Unlike VS Code where you're always typing, Neovim has modes. You switch between them constantly. This is what makes Vim fast once you learn it.

N
Normal Mode
Your home base. Navigate, delete, copy, paste, run commands. Press Esc from any mode to return here. This is where you spend most of your time.
I
Insert Mode
Type text like VS Code. Enter with i (before cursor), a (after cursor), o (new line below). Press Esc to return to Normal.
V
Visual Mode
Select text. Enter with v (character), V (whole line), Ctrl+v (block/column). Then act on the selection: d delete, y copy.

Vim Grammar: Verb + Object

VerbObjectResult
d (delete)w (word)Delete a word
d (delete)i" (inside quotes)Delete inside quotes
c (change)i{ (inside braces)Change inside {braces}
y (yank/copy)ap (a paragraph)Copy a paragraph
> (indent)ib (inside block)Indent inside block

This is Vim's superpower: verbs compose with objects. Learn ~5 verbs (d c y > <) and ~10 objects (w b iw i" i{ ip it ...), and you get 50+ editing commands for free.

Config File Structure

~/.config/nvim/ colors/ chrysaki.lua -- colorscheme (symlinked from dots) lua/ config/ lazy.lua -- bootstraps lazy.nvim plugin manager options.lua -- editor settings (indent, clipboard, etc.) keymaps.lua -- your custom keyboard shortcuts autocmds.lua -- auto-actions (open sidebar on start) plugins/ colorscheme.lua -- sets Chrysaki as default theme lsp.lua -- language servers (bash, sql, glsl) treesitter.lua -- syntax parsers for all languages formatting.lua -- auto-format on save (stylua, prettierd, etc.) editor.lua -- Neo-tree file explorer config git.lua -- gitsigns (inline blame) terminal.lua -- bottom terminal panel config ui.lua -- bufferline tab styling init.lua -- entry point (just loads config/lazy.lua) lazyvim.json -- enabled extras (lang packs, UI features)
