## Decisions Made
- **ctrl+backspace outside tmux**: Ghostty sends `\e[127;5u` (kitty CSI); zsh binds it
  via `bindkey $'\e[127;5u' backward-kill-word`
- **ctrl+backspace inside tmux**: tmux `bind-key -n C-BSpace send-keys M-BSpace` →
  zsh emacs default `\e\x7f` = backward-kill-word. No extra zsh config needed.
- **ctrl+left/right**: Changed from `jump_to_prompt` (Ghostty-level) to
  `csi:1;5D` / `csi:1;5C` so sequences reach zsh; zsh binds `\e[1;5D/C` to word-jump
- **Shader: wave direction**: 8 discrete angles (every 45°), new random angle each cycle
  via hash of `cycleN`. Direction stable for entire wave pass, changes off-screen = invisible
- **Shader: wave front**: straight (no sinusoidal frontVar), parallel band
- **Shader: spin**: only centre-line hexes (`spinPop = exp(-dx²×5.0)`); rotate by `spinPop×π`
- **Shader: grow / pop**: 7-candidate loop (current cell + 6 hex-lattice neighbours at
  offsets `(±1,0)`, `(±0.5,±0.866)`). Each fragment checks if any candidate is spinning,
  renders a `bigD ≤ 1.0` hex (2× normal radius). `localP = hc.xy - OFF[i]` is correct
  for all fragments regardless of Voronoi cell.
- **Shader: white-centre artifact** was `(1-smoothstep(0,0.5,d))×spinPop` fill — removed
- **background-opacity**: 0.92 → 0.96 (darker wallpaper was bleeding through)
- **Vignette floor**: 0.72 → 0.85 (edges were too dark)
- **cellSize**: doubled from 30 → 60 (user wanted larger hexes)
- **Wave speed**: currently 3.0 hex-units/sec, period 80 → ~26 s to cross screen
- **No grain shader**: user rejected; hex wave shader only

## Failed Approaches
- `ctrl+backspace=text:\x17`: Ghostty text: action doesn't expand escapes → sends literal "x17"
- `esc:\x7f` for ctrl+backspace: Ghostty esc: similarly doesn't expand `\x7f`
- `bindkey '^H' backward-kill-word`: zsh plugin load order made it unreliable (plugins
  reset it after .zshrc bindkey section); removed
- `send-keys C-h` in tmux for ctrl+backspace: sent ^H which zsh treated as backward-delete-char
  (single char) not backward-kill-word
- `jump_to_prompt:-1/1` for ctrl+left/right: consumed at Ghostty level, never reached zsh
- `expand = pop * 0.13` (old "grow"): moved edge ring INWARD → hex looked smaller not bigger
- `(1-smoothstep(0,0.5,d))×spinPop` fill: created white centre artifact on bright content
- `rotate waveDir continuously (iTime*0.08)`: wave front rotated mid-screen continuously;
  replaced with per-cycle random angle that only changes when wave is off-screen
- Per-cell random `phaseOffset` for wave front variation: made wave look scattered; replaced
  with straight wave front per user request

## Active Constraints
- Ghostty config changes to `window-padding-*` require new window (not hot-reload)
- `custom-shader-animation = always` keeps GPU busy continuously; intentional
- `chrysaki` is a git submodule. tmux live config is symlinked from dots via stow;
  changes to `chrysaki/tmux/tmux.conf` need `tmux source-file` to take effect
- `.stow-local-ignore` in ghostty package excludes top-level `scripts/` (conflicts with
  rofi's `~/scripts/`); scripts invoked via `~/dots/ghostty/scripts/` path directly
- Hex lattice neighbour offsets for flat-top grid with r=(1,√3): `(±1,0)`, `(±0.5,±0.866)` —
  these are the same for ALL cells (both grid-A and grid-B), verified algebraically
